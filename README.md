# suma-propysom — сума прописом українською

Для рахунків і актів: правильне відмінювання гривні/копійки, тисячі (жіночий рід), мільйона (чоловічий), 11–14.

```python
from suma_propysom import suma_propysom
suma_propysom("1250.50")     # 'Одна тисяча двісті п’ятдесят гривень 50 копійок'
suma_propysom("22.01")       # 'Двадцять дві гривні 01 копійка'
suma_propysom("21000")       # 'Двадцять одна тисяча гривень 00 копійок'
suma_propysom("21", "USD")   # 'Двадцять один долар 00 центів'
```

Копійки за замовчуванням цифрами (як прийнято в документах); `kopecks_as_digits=False` пише словами.

Тести: `python -m unittest -v`
